# 📝 Lista de Tareas (To-Do List)

Este proyecto es una aplicación web sencilla e interactiva para gestionar tareas pendientes. Fue creada para poner en práctica lógica de programación y manipulación del DOM.

🚀 Funcionalidades

* **Gestión de Tareas:** Agregar, marcar como completadas y eliminar tareas.
* **Filtros:** Visualizar tareas por estado (Todas / Pendientes / Completadas).
* **Mood Tracker:** Selector de estado de ánimo diario (Caritas).
* **Bloc de Notas:** Sección para guardar ideas rápidas o recordatorios.
* **Persistencia de Datos:** Todo se guarda en el navegador (LocalStorage) para no perder información.
* **Interfaz Adaptable:** Diseño Responsive que se ve bien en PC y celular.

## 🛠️ Tecnologías utilizadas
- **HTML5:** Estructura semántica.
- **CSS3:** Estilos y diseño visual.
- **JavaScript (ES6):** Lógica y manipulación del DOM.
